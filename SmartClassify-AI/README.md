## Installation

### Clone Repository

```bash
git clone https://github.com/afreen-gul/DeodeLabs.git
```

### Open Folder

```bash
cd SmartClassify-AI
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Train Model

```bash
python train_model.py
```

### Run Application

```bash
python app.py
```
